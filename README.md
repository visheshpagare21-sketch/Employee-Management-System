# Employee Management System

A database-driven Employee Management System built using Python, Tkinter, and MySQL.

## Features

- Add Employee
- Remove Employee
- Promote Employee
- Display Employees

## Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python

## Database Setup

1. Open MySQL.
2. Run the SQL commands from `database.sql`.
3. This will create the `employee_db` database and `employees` table.
